## Recent Releases

<Update label="2024-11-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added support for real-time itinerary sharing via secure links, perfect for group travel planning.
- Introduced advanced filters for busreisen and flug-bus options, including E-Mountainbike compatibility.
- New Excellence Club dashboard with personalized recommendations based on past bookings.

## Improvements

- Optimized search performance for Weihnachtsmärkte and Festtagsreisen, reducing load times by 40%.
- Enhanced mobile responsiveness for Tagesausflüge booking flows.

## Bug Fixes

- Fixed occasional crashes during multi-leg Flussreisen bookings.
- Resolved pricing display issues for Gruppenreisen nach Mass.

</Update>

<Update label="2024-10-20" description="v2.0.0" tags={["feature", "breaking"]}>

- Fixed lost-found report submission errors.

</Update>

## How to Upgrade

Follow these steps to update your TWG instance or SDK to the latest version.

<Steps>
  <Step title="Check Current Version" icon="package">
    Run the version check command:
    
````bash
twg --version
````
  </Step>
  <Step title="Backup Data" icon="database">
    Export your configurations and bookings:
    
````bash
twg export --all > backup.json
````
  </Step>
  <Step title="Install Update" icon="download">
    <Tabs>
      <Tab title="npm" icon="package">
````bash
npm install twg@latest
````
      </Tab>
      <Tab title="yarn" icon="package">
````bash
yarn add twg@latest
````
      </Tab>
    </Tabs>
  </Step>
  <Step title="Verify" icon="check-circle">
    Test core functions:
    
````javascript
import { TWG } from 'twg';
const client = new TWG({ apiKey: 'YOUR_API_KEY' });
console.log(await client.bookings.list());
````
  </Step>
</Steps>
